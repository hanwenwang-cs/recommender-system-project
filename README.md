# Hybrid Recommendation System

This project builds a recommendation system using the MovieLens dataset.

## Requirements

Before running the project, install required libraries:

pip install pandas numpy scikit-surprise matplotlib

## Dataset

This project uses the MovieLens dataset.

Download from:
https://grouplens.org/datasets/movielens/

Use the "ml-latest-small" dataset and place the files in the same folder as the notebook.

## How to Run

1. Open the notebook file
2. Run all cells
3. The outputs will include:
   - RMSE evaluation
   - Top-N recommendations
   - Diversity & Novelty analysis plots

## Notes

- Do not upload large dataset files to GitHub
- Make sure dataset paths are correct before running
