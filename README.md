# Hybrid Recommendation System

## Overview

This project implements a recommendation system using the MovieLens dataset.  
We explore multiple approaches including baseline, SVD, hybrid models, and a learning-based hybrid model.  
In addition to accuracy, we also evaluate diversity and novelty of recommendations.

---

## Requirements

Install required libraries before running the project:

pip install -r requirements.txt

---

## Dataset

This project uses the MovieLens dataset.

Download from:  
https://grouplens.org/datasets/movielens/

Use the "ml-latest-small" dataset and place the files in the same folder as the notebook.

---

## How to Run

1. Open the notebook file (`project.ipynb`)
2. Run all cells
3. The outputs will include:
   - RMSE evaluation
   - Top-N recommendations
   - Diversity & Novelty analysis
   - Visualization plots

---

## Key Features

- Baseline and SVD recommendation models
- Hybrid recommendation model
- Learning-based hybrid model
- Top-N recommendation generation
- Diversity and novelty evaluation
- Visualization of results
